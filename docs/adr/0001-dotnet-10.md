# ADR-0001: Target .NET 10 LTS rather than .NET 8

Date: 2026-09-06. Status: accepted.

**Context.** The brief specified .NET 8. .NET 8 (LTS) leaves support on 10 November 2026; .NET 10
(LTS, November 2025) is the current long-term release and the local toolchain has both SDKs.

**Decision.** Target `net10.0` throughout, with package versions aligned to the 10.0.x train. Nothing
in the codebase relies on features unavailable in .NET 8 beyond the base package versions, so a
downgrade would be a one-line change in `Directory.Build.props` plus package versions.

**Consequences.** Longer support window; the built-in `Microsoft.AspNetCore.OpenApi` document
generator replaces Swashbuckle; App Service uses a container image so the runtime version is
whatever the image carries.
